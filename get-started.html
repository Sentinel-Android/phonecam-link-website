GET STARTED

Set up
PhoneCam Link.

Install both apps, then choose
a connection method.

  1. 01 /

    Install both apps.

    Download the Android app and the Windows installer from our GitHub releases.

  2. 02 /

    Choose a connection.

    Open both apps and follow the connection instructions for your release.

  3. 03 /

    Start the camera feed.

    Start the camera on your phone and bring the view to your PC.

Android 7.0 or newer · Windows 11 x64, build 22000 or newer. Check the selected release for connection and hardware requirements.

CHOOSE YOUR CONNECTION

Connection
instructions.

01 / WI-FI

On the same network.

  1. Connect the phone and PC to the same LAN.
  2. Choose Wi-Fi on Android and press Start camera.
  3. Choose Wi-Fi on Windows, leave Phone address as auto, and press Connect.
02 / USB · ADB

With a USB data cable.

  1. Enable Developer options and USB debugging on Android.
  2. Connect and unlock the phone, then approve the PC’s debugging key.
  3. Select USB · ADB in both apps. Press Start camera on Android, then Connect on Windows.
03 / WI-FI DIRECT

Pair without a router.

  1. On Windows, choose Wi-Fi Direct → Create on this PC → Check and create group.
  2. On Android, choose Wi-Fi Direct → Scan PC QR, then approve the Wi-Fi connection.
  3. Start the camera and use the Windows group-device controls to select/connect the phone.

Compatible Wi-Fi hardware is required. The phone-hosted group is an alternative described in the application’s release notes.

04 / CALL OR STREAM

Choose PhoneCam Link.

Open Google Meet or Zoom camera settings, or add a Video Capture Device in OBS. Select PhoneCam Link when the app exposes it as a camera source. Choose your microphone separately.
