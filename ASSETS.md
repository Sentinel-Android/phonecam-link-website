# Asset provenance

All bitmap art was generated for this project with the built-in image tool, then optimized to WebP. No stock-image service is loaded at runtime. IMAGE-PROMPTS.md records the final edit prompts.

- `galaxy-pair.webp`: unbranded phone/laptop with alpine scenes; manufacturer wordmark removed from the generated hero.
- `video-calls.webp`: people only on laptop video-call tiles. Phone shows PhoneCam Link controls over Wi-Fi. No device logos.
- `live-streaming.webp`: creator only on laptop preview/thumbnails. Phone shows PhoneCam Link controls in USB ADB mode. One continuous visible USB cable connects the phone bottom to the laptop side. No device logos or separate capture device.
- `alpine.webp`, `alpine-small.webp`: original generated alpine landscape, used for nature imagery and illustrative rear-lens crops. `alpine-original.png` retains the original generated output; `social-preview.jpg` is its sharing crop.
- `app-windows.svg`, `app-android.svg`: source-based original vector reconstructions with website blue accents. These are not captured screenshots.
- `app-android-phone.svg`: the Android illustration cropped to a normal phone viewport; no vertical stretching.
- Inline SVG/HTML/CSS: original connection diagrams, lens array, empty-workspace front-camera scene, USB setup walkthrough, pause/play symbols and other icons. No generated human face is used in the lens example.

Selected white adult characters appear only in the two use-case images at the user's request. Discarded front-camera selfie concepts and earlier image variants are not included in the website package.

The camera comparison applies simulated softness to the same nature image. This is disclosed on the page. It is not a device-quality measurement. Lens choices illustrate framing, not guaranteed device lens availability or optical quality. System fonts are used; no font binaries or third-party template assets are bundled.

`favicon-32.png` is a 32×32 rasterization of the original vector `favicon.svg` for browser compatibility. Both are included in the production pages and outer review shell.
